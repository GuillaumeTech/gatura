# Gatura
A geometric serif for display purposes, currently there are 67 glyphs: uppercase, lowercase, numbers and !?-.,

## Specimen
![specimen](specimen.png)

## Why Gatura ?
It's a mix between Futura and Garamond. The font is not a "merge" of these two, it's more that they're representative of their respective groups.
